# 카카오테크 부트캠프 3기 풀스택 과정 ian 2주차 과제 - CLI 멀티스레드 프로그램

### 프로그램 소개
- 야구 게임을 진행할 수 있는 CLI 프로그램입니다.
- 팀과 난이도를 선택할 수 있고, 컴퓨터와 게임을 진행합니다.
- 9회 말 공격만 진행하고, 점수에 따라 승무패가 결정됩니다.

### 멀티스레드 적용 내용
- 사용자 입력 스레드
  - 타격 존을 5초 이내에 입력하지 않으면 자동으로 0번이 선택되도록 구현했습니다.
- 타이머 스레드
  - 타격 존 선택 시 5초 타이머가 출력되도록 구현했습니다.
- 타격 스레드
  - 컴퓨터의 랜덤 투구 존과 사용자가 선택한 타격 존을 토대로 결과를 내도록 구현했습니다.
- 도루 스레드
  - 1루 주자가 특정 확률로 2루 도루를 시도하도록 구현했습니다.
- (사용자 입력 스레드, 타이머 스레드), (타격 스레드, 도루 스레드)와 같이 스레드가 두 개씩 실행되기 때문에 스레드 풀의 스레드 개수는 여유롭게 3개로 설정했습니다.

### 동시성 처리 내용
- 타격 스레드와 도루 스레드는 동시에 실행되고, 각각 베이스와 아웃 카운트를 공유 자원으로 사용합니다.
- 아웃 카운트 변수는 단순히 값 증가, 조회만 필요하므로 AtomicInteger로 선언했습니다.
- 베이스는 (도루 성공, 타자 출루) 시 도루 성공이 먼저 적용되어야 합니다. 각 스레드의 작업에서 하나의 ReentrantLock 객체를 공유했고, Condition을 설정해 도루 작업이 완료되기 전까지 타격 작업은 대기하도록 구현했습니다.
